# Hapa Versus

Two opponents command visible armies on a compact, elevated battlefield. Their connected
territory mints public Minor Arcana that become movement Supply, colored Mana or a Card ability.
Members stand in a visible 3×3 formation; placement decides contact and protection. Win by moving
a party center into the enemy Capital or killing the enemy Commander.

Built from the Hapa Versus Master Requirements v3, Design Companion v1 and References Master v1
(`docs/requirements/`). Work is tracked on the Overwatch board `hapa-versus`.

**Status:** first-pass prototype under active implementation. See the board for what is
implemented, fixture-tested and scheduled.

```bash
npm install
git submodule update --init   # vendor/lumina: the Hapa fork of Luminati
npm run check                 # headless rules tests (+ build once the page exists)
```
